# Engine tasks

Derived from [`folder-tree.md`](folder-tree.md). The live board, where you claim tasks, is in Notion (**R-Type — Architecture › Engine — folder tree & tasks**: https://app.notion.com/p/3f4efac8d89981ba846fe7cddf25ead7). This file is the reference copy. Team: Ola, Sedjro, Michel, Yann-Ange.

Claim a task yourself on the board: set **Owner** and **Status = Claimed**, and the claim date. Nobody assigns tasks to anyone else.
Start a task only when the tasks it depends on are at least *In review*, or agree on the interface with their owner first.
**What each task contains in detail:** click its ID (pages in [`docs/tasks/`](../tasks/README.md)), or open the task on the board.

**Wave** = the order in which tasks can be done: a task's wave is one more than the highest wave of its dependencies, so every task of a wave can be done in parallel once the earlier waves are done. Take your next task from the lowest open wave. Waves count dependencies across both boards (engine and server).
