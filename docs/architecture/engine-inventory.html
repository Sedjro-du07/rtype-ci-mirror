6 · Decided on 2026-10-09

Language, data and tooling

C++23 with an allow-listC++20 except modules, plus std::expected, move_only_function, print, deducing this. Fallback tl::expected. ADR 0017.
Data in YAML, behaviour in scriptsConfig, scenes, prefabs in YAML; waves, boss phases, special AI in scripts. ADR 0018.
Lua firstscripting_lua is the first IScripting plugin; your own language stays optional. ADR 0019.
Game module helpersENGINE_GAME_MODULE, ENGINE_PLUGIN, engine_add_game_module. ADR 0020.
